## 資料

- `data.json` — 結構化資料(欄位:name, city, cat, type, price, level 難度, platform, url 訂位連結, rule 放位規則, ruleType, ruleKey, phone, awards, status, src 來源)
- `index.html` 內亦內嵌同一份 JSON(`<script id="data" type="application/json">`),供後續快速預約提醒程式直接讀取
- `area` — 雙北（台北市／新北市）餐廳的行政區清單，如 `["大安"]`；多分店者列出各分店所在區，查無地址者為 `[]`；其他縣市為 `null`。供 `map.html` 雙北分區地圖使用
- `gmaps` — Google 地圖連結，`[{"n": 分店名或 null, "url": 連結}]`；多分店者依本站已記載的分店各列一筆（`n` 為分店名），單一地點 `n` 為 null。連結用 Google Maps URLs 官方格式（`query` 為店名＋地址、`query_place_id` 為 Google 地點 ID），直接開到該地點。熄燈餐廳、Google 標示「已歇業」或有報導已停業的地點、以及查不到或無法確認是哪一個 Google 地點者為 `null`（不附連結）。卡片顯示為「📍 Google 地圖」
- `dishes`（有 500盤 標籤的條目）— 歷屆《500盤》得獎菜色，`[{"n": 菜名, "y": [得獎年份…]}]`，跨年同名去重；菜名照官方名單圖／官方地圖原文逐字抄錄。卡片顯示為「🍴 500盤得獎菜色 N 道」，搜尋框可搜菜名
- `cathay`（`data.json` 與 `one-plate.json` 都有）— 國泰世華 × inline 卡友專屬訂位名單上有、且確認是本站同一家（連鎖店為同一分店）的店：`"vip"` VIP／頂級卡友專屬餐廳、`"general"` 全卡友專屬餐廳；其他店無此欄。卡片顯示為「國泰VIP」「國泰一般」標籤
- `cards`（`data.json` 與 `one-plate.json` 都有）— 頂級卡特約店家目錄（https://brianann2339.github.io/card-dining-map/）下列權益名單上有、且確認是本站同一家（連鎖店為同一分店；本站一筆列出多個分店地點者，所列分店都在名單上，唯一例外是「富錦樹台菜香檳」：名單只列敦北店，101 旗艦店、大直店不在名單上）的店，值為陣列：`"amex"` 美國運通簽帳白金卡「白金美饌・全台指定餐廳」（目錄裡的「美饌台灣」，2026-09-06 名單；不含 Shop Small、DiningCity 等其他 AMEX 優惠）、`"amex50"` 美國運通 DiningCity Platinum「年度優惠」用餐享5折起（目錄裡的「用餐享5折起」41 家，2026-11-13 與 DiningCity 現行名單核對相同）、`"cw"` 國泰世華世界卡「美饌饗宴」、`"esun"` 玉山世界卡／無限卡（VBO 玉約饗樂、大地酒店、元紀．台灣菜）、`"visa"` Visa 無限卡頂級饗宴、`"mc"` Mastercard 世界卡精選餐飲優惠、`"jcb"` JCB 極緻卡／晶緻卡；其他店無此欄。卡片顯示為「美國運通回饋」「美國運通5折」「國泰世界卡」「玉山世界／無限」「Visa無限卡」「MC世界卡」「JCB極緻／晶緻」標籤，排在「國泰VIP」「國泰一般」之後
- `one-plate.json` — 500盤 一盤餐廳名單（`one-plate.html` 內亦內嵌同一份）：`name` 店名（最近一屆名單寫法）、`names` 其他屆的寫法、`city` 地區（2021 名單未分地區者為「未標地區」）、`area` 台北市／新北市店家的行政區清單（依 2025–2026 官方地圖地址，沒有官方地址者依 Google 地圖或網路查到的地址；名單未標分店、得獎時有多家分店者列出各分店所在區，遷址者新舊址都列，已歇業的分店不列；尚未查到為 `[]`；其他地區無此欄）、`multi` 多分店、得獎時是哪幾家未確認（`area` 為 `[]` 者地圖列在「多分店」，查到來源點名、仍營業的分店者列在分店所在區）、`p500` 得盤年份、`dishes` 得獎菜色、`addr`／`addrYear` 地址與出處年份（僅 2025–2026 官方地圖有）、`phone`（2026 官方地圖；雙北的店以查證結果為準，可能有多支號碼）、`gmaps` Google 地圖連結（雙北查證時認定 Google 地點的店帶 `query_place_id` 直接開到該地點，其餘用店名加地址搜尋）、`lists` 各屆名單上的寫法與名單圖列數、`src` 來源；雙北未歇業的店另有查證欄位：`chk` 查證年月、`st` 營業狀態（`open` Google 地圖未標歇業／`unk` 找不到 Google 地點／`paused` 暫停營業）、`rule` 訂位方式說明、`ruleType` 訂位類別（同主站，查不到者無此欄）、`url` 訂位頁、`sns` 官方社群訂位入口、`opNote` 查證備註；`closed` 已歇業（`closedBy: "google"` 表示只有 Google 地圖標示歇業），雙北分區地圖不列
