# 台灣預約困難餐廳圖鑑 tw_difficult_restaurant

40 間台灣預約困難餐廳的互動圖鑑(2026 年 7 月查證):訂位平台、放位規則(每月幾號幾點開搶)、價位、米其林/500盤紀錄,可依縣市/類型/放位方式篩選。

🌐 網頁:https://brianann2339.github.io/tw_difficult_restaurant/
🗺 雙北分區地圖:https://brianann2339.github.io/tw_difficult_restaurant/map.html（點選或勾選台北市／新北市的區，列出該區餐廳；區界取自 OpenStreetMap）

## 資料

- `data.json` — 結構化資料(欄位:name, city, cat, type, price, level 難度, platform, url 訂位連結, rule 放位規則, ruleType, ruleKey, phone, awards, status, src 來源)
- `index.html` 內亦內嵌同一份 JSON(`<script id="data" type="application/json">`),供後續快速預約提醒程式直接讀取
- `area` — 雙北（台北市／新北市）餐廳的行政區清單，如 `["大安"]`；多分店者列出各分店所在區，查無地址者為 `[]`；其他縣市為 `null`。供 `map.html` 雙北分區地圖使用
- `gmaps` — Google 地圖連結，`[{"n": 分店名或 null, "url": 連結}]`；多分店者依本站已記載的分店各列一筆（`n` 為分店名），單一地點 `n` 為 null。連結用 Google Maps URLs 官方格式（`query` 為店名＋地址、`query_place_id` 為 Google 地點 ID），直接開到該地點。熄燈餐廳、Google 標示「已歇業」或有報導已停業的地點、以及查不到或無法確認是哪一個 Google 地點者為 `null`（不附連結）。卡片顯示為「📍 Google 地圖」
- `dishes`（有 500盤 標籤的條目）— 歷屆《500盤》得獎菜色，`[{"n": 菜名, "y": [得獎年份…]}]`，跨年同名去重；菜名照官方名單圖／官方地圖原文逐字抄錄。卡片顯示為「🍴 500盤得獎菜色 N 道」，搜尋框可搜菜名

## 難度分級

傳說級(熟客/引薦制)/秒殺級(開放即搶空)/困難(需提前數週至數月)/熱門(需預約但可訂)

## 免責

各店放位規則、價格、營業狀態隨時可能調整,請以官方 IG/FB/官網最新公告為準。資料彙整自 Marie Claire、KKTL 越境食旅、愛飯團、台灣米其林指南、500盤及各店官方頁面(來源附於各卡片)。
